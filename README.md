# simple-linear-regression
My first Machine Learning project using Simple Linear Regression

## Project Overview
This project uses Simple Linear Regression to predict salary based on years of experience.

## Algorithm
- Simple Linear Regression

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Dataset
The dataset contains years of experience and corresponding salary values.

## Project Workflow
1. Load the dataset.
2. Explore and prepare the data.
3. Split the data into training and testing sets.
4. Train the Simple Linear Regression model.
5. Make predictions.
6. Evaluate model performance.

## Model Saving
The trained model is saved using Python's Pickle library for future use.

## Current Status
Model training and model saving are implemented. Deployment has not been completed yet.

## How to Run
1. Install the required libraries.
2. Run the model creation file.
3. Run the model saving file.
